# 스탑워치

분류. Prototype (7점). 설치 없이 `index.html`을 브라우저로 열면 동작하는 한 장짜리 스탑워치다.

## 사용법

| 동작 | 버튼 | 단축키 |
|---|---|---|
| 시작, 정지, 계속 | 오른쪽 버튼 | `Space` |
| 랩 기록 | 왼쪽 버튼 (작동 중) | `L` |
| 초기화 | 왼쪽 버튼 (정지 중) | `R` |

- 랩 목록은 최신 랩이 위에 온다. 랩이 3개 이상이면 가장 빠른 랩은 초록, 가장 느린 랩은 빨강으로 표시한다.
- 상태(누적 시간, 작동 여부, 랩)는 브라우저 `localStorage`에 저장한다. 새로고침하거나 탭을 닫았다 열어도 이어서 잰다. 저장이 막힌 환경(시크릿 창 등)에서는 저장만 빠지고 나머지는 그대로 동작한다.
- 시스템 다크 모드를 따른다.

## 구조

- 외부 라이브러리 없음. HTML, CSS, JS가 `index.html` 한 파일에 있다.
- 시간은 `Date.now()` 기준으로 계산한다. 화면 갱신 주기와 무관하게 누적 시간이 정확하고, 새로고침 후에도 이어 갈 수 있다.

## 갱신 기준

- 기능을 더할 때(카운트다운, 랩 CSV 내보내기 등) 이 표와 설명을 함께 고친다.
- 반복해서 쓰는 도구가 되면 그때 Core Asset 승격을 검토한다.
